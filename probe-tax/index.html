캘린더 등록 실기 시험

이 페이지는 실기 확인용 임시 시험 페이지입니다. 일반 이용자용 서비스가 아닙니다.

시험용 페이지입니다. 각 버튼을 누르고, 결과를 아래 체크칸에 표시한 뒤 화면을 캡처하십시오. 아무것도 저장·전송되지 않습니다.

인앱 브라우저로 보입니다(추정, UA 기반이라 틀릴 수 있음) — 외부 브라우저(Safari·Chrome 등)로 열어 주십시오.

① .ics 내려받기 (단일 일정)

누르면 파일이 내려받아지고, 열었을 때 캘린더 앱이 뜨며 2027-01-25 종일 일정(하루 전 알림)이 들어가면 성공.

①s .ics 정적 파일 링크 (단일 일정)

[시험] 부가세 확정신고 .ics (정적 파일 링크)

①과 같은 내용을 정적 파일로 — blob 이 막혀도 이건 통하는지 보려는 것. 일반 링크이며 download 속성 없음.

② .ics 내려받기 (매월 반복)

캘린더에 매월 10일 반복 일정으로 들어가면 성공(2027-01-10부터). 한 건만 들어가면 반복 실패.

②s .ics 정적 파일 링크 (매월 반복)

[시험] 원천세 신고 .ics (정적 파일 링크)

②과 같은 내용을 정적 파일로 — blob 이 막혀도 이건 통하는지 보려는 것. 일반 링크이며 download 속성 없음.

③ 구글 캘린더 링크 (단일)

구글 캘린더로 추가 (1/25)

누르면 구글 캘린더(앱 또는 웹)에 일정 작성 화면이 뜨고, 2027-01-25 종일로 채워져 있으면 성공. 파일 다운로드 없음.

④ 구글 캘린더 링크 (매월 반복)

구글 캘린더로 추가 (매월 10일)

작성 화면에서 반복이 「매월 10일」로 채워져 있으면 recur 성공. 반복이 「반복 안함」이면 recur 가 무시된 것(핵심 확인 항목).

recur 조사 결과: 공식 문서에는 없는 비공식(미문서화) 파라미터로 보임. 블로그 등에서 recur=RRULE:... 형태가 쓰인다는 언급은 있음(출처: dylanbeattie.net 2021 글, datebook 라이브러리 README). 공식 확인은 못 함 - 실측 필요. 모바일 앱에서 먹는지는 미확인.
